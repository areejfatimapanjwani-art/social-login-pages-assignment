# Social Login Pages — GitHub Assignment

## Projects included
- `facebook-login-demo/` — a Facebook-style classroom login page.
- `instagram-auth-demo/` — an Instagram-style classroom authentication page.

## Technologies
HTML, CSS and JavaScript.

## How to run
1. Download or extract this folder.
2. Open either project folder.
3. Double-click `index.html` to open it in a browser.

## Important safety note
These are independent educational front-end mockups, not official Facebook or Instagram pages. They do not connect to either service, send form data, or store passwords. Do not enter real account details.

## GitHub submission
Create one **Public** repository, for example `social-login-pages-assignment`, and upload both project folders and this README. Copy the repository URL and submit it on your LMS.
